# Changelog

Newest first. The first section holds every change made after the method was frozen (tag `v1.0-prereg`, see [PREREG.md](PREREG.md)), including any Void run and any task version bump. The second holds the drafts before the freeze.

## After pre-registration

- Move and CI (2026-11-20; no scores, rules or results changed): The repository moved to the promptingcompany organization and links now point there. CI gains a 10-minute timeout and a step that compiles every Python file. The vendor-name check moved out of CI into `scripts/check_names.sh`, run locally before every push: it now searches every commit and commit message, and the name list is no longer stored on GitHub, even as a secret.
- CI and check fixes (2026-11-19): the vendor-name step fails on a bad pattern; the README headline is checked against summary.csv; check-anon wording corrected.
- Retention (2026-11-19): PRIVACY.md now says the gold-email key, the verifier cache and the candidate pool are kept after the 90-day window, and why.
- Archived sources (2026-11-19): `datasets/public/w1-firmographics-sources.csv` lists the SEC filing behind each public firmographic answer-key row (89) with a Wayback Machine copy. Held-out rows and the gold-email key's sources are not listed.
- Disclosure (2026-11-19, editorial): removed an incorrect statement that Clay is a client of The Prompting Company, and the related statement about payment. Clay is not a client.
- Layout (2026-11-19; no content changes): docs moved into `docs/`; README gains a pipeline diagram.
- Documentation (2026-11-19; no scores, rules or results changed): added a privacy statement (PRIVACY.md), a data dictionary (DATA-DICTIONARY.md), a "results as of" note (RESULTS.md, BENCHMARK-CARD.md), a CC BY 4.0 licence for the documentation and results (LICENSE-DOCS; code stays MIT) and a versions and dates table (RESULTS.md). RESULTS.md's status line gave the run dates as 7–10 November 2026; the run records show all four runs on 7 November (UTC), with checking, pricing and scoring done by 10 November, and it now says so.
- **Publication cleanup (2026-11-19; no scores, rules or results changed).**
  - **Results moved to RESULTS.md.** Its tables are generated from `results/summary.csv` by `scripts/check_results.py` and checked in CI. They again show cost per 1,000 verified emails and median latency, and now show right-person rate, all from `summary.csv`.
  - **Confidence intervals added.** The tables show a 95% Wilson score interval for verified email rate, valid mobile rate and right-person rate, worked out from the rates in `summary.csv`. RESULTS.md says which differences fall outside each other's intervals and which don't.
  - **Editorial fixes to the pre-registered text** (METHODOLOGY.md, tasks/W1-v1.md, ANSWER-KEYS.md, DATA.md). The frozen text can still be checked as PREREG.md describes.
    - Wording corrected to match what was done: the Provider A and B adapters are not published; SIRENE, DART and EDINET were not used; the gold subset is at least 100 rows (128 built) and the firmographic sample is 196 rows, checked by machine against their sources, not by hand; enriched outputs are kept in the gitignored `private/` folder.
    - Per-vendor request pacing and internal decision labels removed from the task file and the method. The quality floor is no longer marked "proposed".
    - METHODOLOGY.md status line: the pre-run note is replaced by the current status. The list of sales questions (section 1) and the empty section 13 are removed, and section 12 describes the results page plainly.
    - References to another of our benchmarks removed. The rules they pointed to are now written out: list prices only (section 7) and what each run status means (section 8).
    - **Firmographic accuracy denominator.** The method (section 6) said "sample rows returned" and the task file said 200 rows. The scoring code has always divided by the answer-key rows that have a value: 196 for employee band and for country, and 170 for industry and for all three together, with a blank output counted as a miss. The text now matches the code (METHODOLOGY.md sections 3 and 6, tasks/W1-v1.md, DATA.md, README, RESULTS.md).

    - Terms of service (section 11) reworded. A vendor-specific parameter name removed from Provider B's phone policy (section 5, rule 9), and from this changelog.
    - Canary string: the line at the end of tasks/W1-v1.md and DATA.md is now plain text, with the same GUID as before, and RESULTS.md ends with it too. The canary bullet in METHODOLOGY.md section 9 is shortened to match.
  - **Checks and reproducibility.** `scripts/reproduce.sh` runs every check in one command and, with the private run folders, re-scores them. REPRODUCTIONS.md logs reproduction attempts. BENCHMARK-CARD.md, `.zenodo.json` and `.python-version` added. benchkit is pinned by commit (v0.1.3; published scores were computed at v0.1.0, and scoring is unchanged since). The published-numbers check accepts any figure in the README's Results that `summary.csv` gives, checks the intervals, and has a test that a changed number fails. CI skips the vendor-name check on pull requests that can't read its secret.
  - **Unmapped HQ countries are logged.** An adapter now prints a country name it can't turn into an ISO code, as the scorer already does for industry labels. The published runs had five such rows (four from Provider B, one from Provider A). One was in the firmographic sample, where its country was a miss either way, so no score changes.
  - **Housekeeping.** Clay function IDs removed from `.env.example`. This repository will move to github.com/promptingcompany, published without its working history; the pre-registration commit is kept in a private archive and can be checked on request (PREREG.md).
